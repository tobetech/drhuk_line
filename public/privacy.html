1. ข้อมูลที่เราเก็บและใช้

ข้อมูลที่มาใช้เพื่อ
รหัสผู้ใช้ LINE (User ID)ได้รับจาก LINE เมื่อคุณส่งข้อความหรือเพิ่มเพื่อนตอบกลับคุณ และคำนวณใบเซียมซีประจำวันให้เป็นใบเดิมในวันเดียวกัน
ข้อความที่คุณพิมพ์ถึงบัญชีคุณส่งเองตรวจคำสั่ง เช่น "เสี่ยงเซียมซี" เพื่อตอบกลับ
ข้อมูลทางเทคนิคของเซิร์ฟเวอร์ (บันทึกข้อผิดพลาด เวลา และที่อยู่ IP ที่ผู้ให้บริการโฮสติ้งบันทึก)ระบบเซิร์ฟเวอร์รักษาความปลอดภัยและแก้ไขข้อขัดข้อง

เราไม่ขอข้อมูลอ่อนไหว ไม่ขอชื่อจริง เบอร์โทร ที่อยู่ หรือข้อมูลการเงินผ่านบริการนี้ และขอให้คุณไม่ส่งข้อมูลเหล่านี้มาในแชท

ตามการตั้งค่าเริ่มต้นของระบบ ตัวบอทไม่บันทึก User ID และข้อความของคุณลงฐานข้อมูล ข้อมูลถูกประมวลผลชั่วคราวเพื่อตอบกลับเท่านั้น ส่วนประวัติแชทที่แอดมินเห็นในโหมดแชทของ LINE OA เป็นข้อมูลที่ LINE จัดเก็บตามเงื่อนไขของ LINE

4. ระยะเวลาเก็บรักษา

บันทึกทางเทคนิคของเซิร์ฟเวอร์เก็บไม่เกิน [30] วัน แล้วลบหรือทำให้ไม่สามารถระบุตัวตนได้ ข้อมูลอื่นที่เราไม่ได้บันทึกย่อมไม่มีระยะเก็บรักษา หากมีการเก็บข้อมูลเพิ่ม เราจะปรับเอกสารนี้และแจ้งให้ทราบ

5. สิทธิของคุณตาม PDPA

คุณมีสิทธิเข้าถึงและขอสำเนา, ขอแก้ไขให้ถูกต้อง, ขอลบหรือทำลาย, ขอให้ระงับการใช้, คัดค้านการประมวลผล, ขอโอนย้ายข้อมูล และถอนความยินยอมที่เคยให้ ส่งคำขอได้ที่ [อีเมลติดต่อ] เราจะตอบภายใน 30 วัน หากเห็นว่าเราละเมิดกฎหมาย คุณมีสิทธิร้องเรียนต่อคณะกรรมการคุ้มครองข้อมูลส่วนบุคคล

คุณหยุดใช้บริการได้ทุกเมื่อ โดยบล็อกหรือลบบัญชีนี้ออกจากรายชื่อเพื่อนใน LINE
